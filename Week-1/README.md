# Week 1 — Data Cleaning, Visualization & Sales Dashboard

## Overview

This project focuses on cleaning and analyzing an **Online Retail** transaction dataset and presenting sales insights through an interactive **Power BI dashboard**.

The workflow covers data preparation in Python, exploratory analysis, visualization, and dashboard development in Power BI.

## Objectives

- Inspect and understand the retail transaction data.
- Clean and preprocess the dataset for analysis.
- Perform exploratory analysis and visualization.
- Create meaningful sales KPIs and visualizations.
- Build an interactive Power BI sales dashboard.
- Communicate sales trends and insights visually.

## Dataset

The project uses an **Online Retail** transaction dataset containing retail sales records.

- `Online Retail.xlsx` — original source dataset.
- `cleaned_online_retail.zip` — compressed cleaned dataset used in the project.

## Data Preparation

The notebook covers the data cleaning and visualization workflow, including preparing the retail transaction data for analysis.

### Workflow

1. Load and inspect the dataset.
2. Identify and handle data-quality issues.
3. Prepare the cleaned dataset.
4. Perform exploratory analysis.
5. Create sales visualizations.
6. Build the Power BI dashboard.

## Power BI Sales Dashboard

The completed dashboard is titled **SALES DASHBOARD** and includes key performance indicators and sales visualizations.

### Key Performance Indicators

- **Total Orders:** 19.96K
- **Total Sales:** 7.18M
- **Total Products:** 3.81K
- **Total Customers:** 4.34K
- **Total Countries:** 38

### Dashboard Visualizations

- Monthly sales trend
- Top 10 countries by sales
- Top 10 products by sales
- Sales performance KPIs
