# Week 3 — Netflix Exploratory Data Analysis

## Overview

This project focuses on performing **Exploratory Data Analysis (EDA)** on the Netflix Titles dataset to understand the content available on the platform and identify meaningful patterns and trends.

The workflow covers data inspection, cleaning, exploratory analysis, statistical analysis, and visualization using Python.

## Objectives

- Understand the structure of the Netflix dataset.
- Inspect and preprocess the data.
- Analyze the distribution of Movies and TV Shows.
- Explore content by country.
- Analyze release years and content trends.
- Study ratings and content categories.
- Explore genres and other relevant attributes.
- Create meaningful visualizations.
- Extract useful insights from the dataset.

## Dataset

The project uses the **Netflix Titles** dataset containing information about movies and TV shows available on Netflix.

### Main Attributes

- `show_id`
- `type`
- `title`
- `director`
- `cast`
- `country`
- `date_added`
- `release_year`
- `rating`
- `duration`
- `listed_in`
- `description`

## Analysis Performed

The analysis includes:

1. Dataset inspection and understanding.
2. Data cleaning and preprocessing.
3. Analysis of Movies vs TV Shows.
4. Analysis of content by release year.
5. Analysis of content ratings.
6. Country-wise content analysis.
7. Genre and category analysis.
8. Exploratory visualizations.
9. Identification of trends and patterns.
10. Summary of key findings.

## Visualizations

The project includes visual analysis to understand:

- Distribution of Movies and TV Shows
- Release-year trends
- Content ratings
- Country-wise content distribution
- Genre/category distribution
- Other relationships and patterns in the dataset

This project provided practical experience in **data cleaning, exploratory data analysis, statistical analysis, data visualization, identifying trends, and communicating insights from real-world data**.

## Conclusion

The project demonstrates how exploratory data analysis can be used to understand a large content dataset and identify patterns related to content type, release years, ratings, countries, and genres.
