# Thiranex Internship

This repository contains my completed work from the **Thiranex internship**, organized by week. The projects cover data cleaning, exploratory data analysis, data visualization, Power BI dashboard development, machine learning, and predictive modeling using real-world datasets.

## Weekly Projects

### Week 1 — Data Cleaning, Visualization & Sales Dashboard

- Cleaned and prepared an **Online Retail** transaction dataset.
- Performed exploratory analysis and sales visualization.
- Built an interactive **Power BI Sales Dashboard** with key sales KPIs and visualizations.
- Technologies: Python, Pandas, NumPy, Matplotlib, Seaborn, Power BI.

### Week 2 — Wine Quality Prediction

- Applied supervised machine learning to predict wine quality.
- Trained and compared **Decision Tree** and **Random Forest** classifiers.
- Evaluated models using Accuracy, Precision, Recall, F1 Score, ROC-AUC, and confusion matrices.
- Random Forest achieved the better overall performance.
- Technologies: Python, Pandas, Scikit-learn, Matplotlib, Google Colab.

### Week 3 — Netflix Exploratory Data Analysis

- Performed exploratory data analysis on the **Netflix Titles** dataset.
- Analyzed content types, release years, ratings, countries, genres, and other content characteristics.
- Created visualizations to identify patterns and trends in the dataset.
- Documented the analysis and findings in a project report.
- Technologies: Python, Pandas, NumPy, Matplotlib, Seaborn, Google Colab.

### Week 4 — Big Mart Sales Prediction

- Performed exploratory analysis on the **Big Mart Sales** dataset.
- Prepared product and outlet features for machine learning.
- Trained and compared **Linear Regression, Decision Tree, and Random Forest** regression models.
- Evaluated models using MAE, RMSE, and R² Score.
- Random Forest achieved the best performance with an **R² Score of 0.6052**.
- Generated sales predictions for the test dataset.
- Technologies: Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Google Colab.
